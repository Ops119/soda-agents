# Launch assistant

A checklist for a token launch you run yourself. This pack does not deploy a program, create a pool, or submit a transaction.

1. Write the token name, symbol, decimals, and total supply before you touch a wallet.
2. Decide who can mint and freeze, and whether those authorities will be revoked. Write that decision down.
3. Use a throwaway devnet wallet first. Fund it from a devnet faucet, not from a wallet that holds mainnet assets.
4. Create the mint on devnet and send a test transfer to a second wallet you control.
5. Publish the mint address, the authorities you kept, and the supply. If you cannot explain an authority, do not ship it.
6. Liquidity, if you add any, comes from a wallet you control. This checklist will not move it for you.

Nothing in this pack is financial, legal, or security advice.
