# Hardware ROI planner

A workbook for a DePIN machine you are thinking about buying. It does not forecast a token price and it does not connect to a wallet.

Fill in `assumptions.csv`, then compare payback months:

`payback months = hardware cost / (monthly rewards − monthly power − monthly rent)`

If monthly rewards do not cover power and rent, there is no payback. Treat every rewards number as an assumption you can be wrong about.
